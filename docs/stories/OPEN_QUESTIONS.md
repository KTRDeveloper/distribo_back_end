## Answers
<!-- One line per answer, for example: Q-001: <answer> -->
Q-001: No real data exists in any database. Drop everything, start the database from scratch and reset all existing migrations into one fresh baseline. No expand, migrate, contract stories; Q-019 is moot (old bcrypt hashes need no support).
Q-002: Keep tasks, remote-config, api-docs and metrics untouched; one change story retargets Task ownership from Account to Person.
Q-017: The five packages in ADR-002 are approved (@casl/ability 7.0.1, argon2 0.45.1, libphonenumber-js 1.13.14, uuid 14.0.2, otplib 13.5.0).
Q-019: Moot after Q-001. Argon2id replaces bcrypt directly; bcrypt is removed from the allowlist once the last story that used it is gone.
Q-011: Answered by design v16 (`finances/subscription`): the plans are FREE, ESSENTIAL, PRO and ENTERPRISE (FND-014, BIL stories); the free plan allows 2 collaborators and 30 products; a plan period is created by the server after a payment or by an administrator gesture (BIL), not by the owner.
Q-048: User approved adding `tests/integration/sync/pull-identity-removed-fields.test.ts` to ORG-032's Tests to update: remove only the obsolete organization email fixture field, keep all non-disclosure assertions. For ORG-043, live means `deleted_at IS NULL`: only non-deleted flagged collaborations block the migration; soft-deleted flagged rows do not block and their retired flag is discarded with the column. Add `deleted_at timestamptz` to the scratch table and test both cases explicitly. ORG-043 also removes only the three obsolete `isPublicContact: true` fixture fields in the same sync test file, retaining every non-disclosure and scope assertion. Keep the existing registered-person rule, ids-only diagnostic and no automatic conversion into contacts. User also approved adding `tests/integration/organization/lookup-contacts.test.ts` and `tests/integration/organization/public-contact-removed.test.ts` to ORG-043's Tests to update: retire only fixtures and assertions tied to the dropped flag, preserve all access, scope and privacy checks, and fix the latter file's unsafe array return with explicit typing, without disabling any lint rule.
