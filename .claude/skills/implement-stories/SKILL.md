# Implement stories

The selection and options come from $ARGUMENTS.

## Selection (combine freely)
- `AUTH-003`, or a list: `AUTH-003,AUTH-005`
- `AUTH-003..AUTH-007`: a range within one module
- `module:auth`: every active story of a module
- `next:N`: the first N todo stories, in order, whose dependencies are done or earlier in the list
- `all`: every todo story
- `kind:<kind>` and `risk:<level>`: filters that narrow the selection
Options: `--with-deps`, `--include-blocked`, `--keep-going`, `--plan`, `--stories <folder>`.

## Resolve
Run `node .claude/skills/implement-stories/scripts/select.mjs $ARGUMENTS` and follow its output. Never read STATUS.md, _meta/order.md or story files to resolve a selection: the script applies every rule (skip done and obsolete stories, blocked ones unless named or `--include-blocked`, in_progress ones unless named; every dependency done or selected; the order of _meta/order.md, whatever the order typed). It prints one line per item:
- `PLAN <ID> <risk> <path> <title>`: the stories to implement, in order (`PLAN none` when there are none);
- `SKIP <ID> <reason>`: the stories left out, with the reason;
- `UNKNOWN <selector>` or `MISSING <ID> needs <dependency> (<status>)`, with exit code 2: stop and report them. `--with-deps` adds missing todo dependencies.

With `--plan`, print these lines and stop.

## Run, one story at a time
For each `PLAN` line, in order:
1. Delegate the story to the story-implementer subagent, passing only its path. Never pass other stories: each story gets a fresh context.
2. Wait until the subagent has finished (it may run in the background) before doing anything else.
3. Then read only the story's line, with `grep -m1 "| <ID> |" <stories folder>/STATUS.md`:
   - done: commit with the message `<ID>: <title>`, then continue;
   - in_progress with the note "ready for review" (risk: high): commit, then skip the stories that depend on it;
   - blocked or anything else: stop. With `--keep-going`, continue only with stories that don't depend on it.
4. Never edit story files or CONVENTIONS.md yourself.

## Summary
List the stories implemented, awaiting review, blocked (with their notes) and skipped, and suggest the next command to run.
